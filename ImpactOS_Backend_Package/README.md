# ImpactOS Backend Package

**Copy `backend/` into your ImpactOS repository root.** Include `sample_data/demo_projects.csv` alongside it because the demo endpoint reads that file. Or copy the entire extracted package into an empty repository.

No solver algorithm is included. Keep Person 3's `optimizer/` folder at the repository root.

See `backend/README.md` for commands and `docs/API_CONTRACT.md` for integration details.
